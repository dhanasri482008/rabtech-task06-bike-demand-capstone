# RabTech Academy – Task 06: Data Science Research Capstone & Whitepaper

## Project
**Predicting Hourly Bike-Sharing Demand Using Machine Learning and Weather/Calendar Features**

This capstone consolidates the earlier RabTech bike-sharing work (Tasks 02–04) using the UCI Bike Sharing Dataset (`hour.csv`). The research target is hourly total rentals (`cnt`).

## Dataset
The notebook downloads the dataset through the `ucimlrepo` package (UCI dataset ID 275). The original dataset contains hourly and daily rental counts from 2011–2012 with weather and calendar information. Cite Hadi Fanaee-T (2013), UCI Machine Learning Repository, DOI: 10.24432/C5W894. License: CC BY 4.0.

**Important:** `casual` and `registered` are excluded from predictors because their sum is the target `cnt` (target leakage). `instant` is an identifier and is also excluded.

## Run in VS Code
1. Extract the ZIP and open this folder in VS Code.
2. Open Terminal in this folder.
3. Install packages:
   `python -m pip install -r requirements.txt`
4. Open `notebooks/task06_bike_demand_capstone.ipynb`.
5. Select your Python kernel and choose **Run All**.
6. The notebook downloads the UCI dataset, performs EDA, trains models, evaluates a time-ordered holdout, saves metrics/predictions/plots, and creates a results-filled PDF report under `reports/`.

If network access prevents automatic download, download `hour.csv` from the UCI Bike Sharing Dataset page and save it as `data/hour.csv`, then rerun the notebook.

## Research question
How accurately can hourly bike-sharing demand be predicted from weather, time, and calendar variables, and which model provides the best balance of predictive accuracy and interpretability?

## Methodology
- Data validation and exploratory data analysis
- Time-ordered 80/20 train-test split (no random shuffling)
- Baseline: training-set median
- Models: Linear Regression, Random Forest Regressor, HistGradientBoosting Regressor
- Metrics: MAE, RMSE, R², and MAPE on non-zero actual counts
- Model selection based on holdout MAE/RMSE, with limitations discussed
